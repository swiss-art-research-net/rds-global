How it works

RDS uses equivalence links found in the source data, such as sameAs, to link records across datasets and group records that refer to the same entity into one result. Within that group, each row represents an individual dataset record. Enter a name and optionally limit the search by dataset and/or entity type. Expand a result to compare the available records and see how the entity is represented in each dataset.
